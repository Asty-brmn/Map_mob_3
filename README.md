# Map_mob_3
Маркеры на карте - Мобильное приложение React Native приложение для создания маркеров на карте с возможностью добавления фотографий к каждому маркеру.
# Приложение "Карта маркеров" с GPS-трекингом и уведомлениями

Мобильное приложение для создания меток на карте с отслеживанием местоположения и локальными уведомлениями о приближении к сохраненным точкам.

## Основные функции

### Геолокация
- Отслеживание текущего местоположения в реальном времени
- Обновление координат каждые 5 секунд или при перемещении на 5+ метров
- Отображение позиции пользователя на карте (синий маркер)

### Маркеры на карте
- Создание маркеров долгим нажатием на карту
- Автоматическое название "Маркер N"
- Просмотр, редактирование и удаление маркеров
- Прикрепление изображений к маркерам

### Локальные уведомления
- Уведомления при приближении к маркерам (100 метров)
- Предотвращение дублирования уведомлений
- Автоматическая очистка уведомлений при выходе из зоны
- Без звука (соответствие требованиям задания)

### Интерфейс
- Два режима отображения: карта и список
- Визуализация зон приближения (круги 100м)
- Панель управления с кнопками включения/выключения отслеживания
- Информация о количестве маркеров и ближайших

## Технологический стек

- **React Native** с **Expo**
- **TypeScript** для типизации
- **Expo Router** для навигации
- **SQLite** для локального хранения данных
- **React Native Maps** для карт
- **Expo Location** для геолокации
- **Expo Notifications** для локальных уведомлений

## Использование

### Создание маркера
1. Откройте приложение
2. Перейдите на вкладку "Карта"
3. Нажмите и удерживайте место на карте

1. Нажмите на маркер на карте
2. Нажмите кнопку "Детали"
3. На экране деталей можно:
   - Добавить изображения
   - Удалить маркер
   - Просмотреть координаты

### Включение отслеживания
1. Нажмите кнопку "📍 Вкл" в верхней панели
2. Разрешите доступ к геолокации
3. Ваше местоположение отобразится на карте

### Тестирование уведомлений
1. Создайте маркер
2. Отойдите на 150+ метров от него
3. Вернитесь к маркеру
4. На расстоянии 100 метров получите уведомление

## Архитектура

### Система геолокации
- **LocationService** - сервис для работы с GPS
- Использует формулу Хаверсина для расчета расстояний
- Проверяет приближение к маркерам каждые 5 секунд
- Управляет разрешениями и ошибками

### Система уведомлений
- **NotificationManager** - сервис для локальных уведомлений
- Создает канал уведомлений для Android
- Предотвращает дублирование через Map активных уведомлений
- Автоматически очищает уведомления через 5 минут

### База данных
- SQLite для локального хранения
- Две таблицы: markers и marker_images
- Связь один-ко-многим между маркерами и изображениями
- Автоматическое создание демо-данных при первой инициализации

### Контекст данных
- **DatabaseContext** - единая точка доступа к данным
- Объединяет операции с БД, геолокацией и уведомлениями
- Предоставляет хуки для использования в компонентах

## Ключевые особенности реализации

### Расчет расстояний
```typescript
// Формула Хаверсина для точного расчета
calculateDistance(lat1, lon1, lat2, lon2): number {
  const R = 6371e3; // Радиус Земли в метрах
  const φ1 = lat1 * Math.PI / 180;
  const φ2 = lat2 * Math.PI / 180;
  const Δφ = (lat2 - lat1) * Math.PI / 180;
  const Δλ = (lon2 - lon1) * Math.PI / 180;

  const a = Math.sin(Δφ/2) * Math.sin(Δφ/2) +
            Math.cos(φ1) * Math.cos(φ2) *
            Math.sin(Δλ/2) * Math.sin(Δλ/2);
  const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));

  return R * c;
}
```

### Предотвращение дублирования уведомлений
```typescript
// Хранение активных уведомлений в Map
private activeNotifications: Map<number, ActiveNotification> = new Map();

// Проверка перед показом
hasActiveNotification(markerId: number): boolean {
  return this.activeNotifications.has(markerId);
}

// Удаление при выходе из зоны
removeNotification(markerId: number): void {
  this.activeNotifications.delete(markerId);
}
```

### Логика проверки приближения
```typescript
if (distance <= PROXIMITY_THRESHOLD) {
  // В зоне: показать уведомление, если еще не показывали
  if (!notificationManager.hasActiveNotification(marker.id)) {
    notificationManager.showNotification(marker);
  }
} else {
  // Вне зоны: удалить уведомление, если было
  if (notificationManager.hasActiveNotification(marker.id)) {
    notificationManager.removeNotification(marker.id);
  }
}
```

## Ограничения

### В Expo Go
- Локальные уведомления работают в ограниченном режиме
- Push-уведомления не поддерживаются
- Некоторые функции Android каналов могут не работать

### На разных платформах
- **Android**: требуется создание канала уведомлений
- **iOS**: требуется настройка разрешений в Info.plist
- **Web**: некоторые функции геолокации ограничены

### Производительность
- При большом количестве маркеров (>100) возможны задержки
- Рекомендуется использовать пагинацию для списков
